## ⚙️ Cara Update Script

</div>

| Step | Aksi |
|:----:|:-----|
| **1** | Edit file `.lua` di GitHub |
| **2** | Naikkan `SCRIPT_VERSION` (contoh: `1.0.0` → `1.0.1`) |
| **3** | Update juga file `.version` dengan angka yang sama |
| **4** | Commit changes |

| File | Sebelum | Sesudah |
|:-----|:-------:|:-------:|
| `bloxfruits.lua` | `SCRIPT_VERSION = "1.0.0"` | `SCRIPT_VERSION = "1.0.1"` |
| `bloxfruits.version` | `1.0.0` | `1.0.1` |

User yang masih pakai `1.0.0` bakal **otomatis ke-update**. 🚀
